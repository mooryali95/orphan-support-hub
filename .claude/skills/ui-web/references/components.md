# بناء المكوّنات

## مبادئ المكوّن المحبوب
1. **الافتراضيات الجيدة أهم من الخيارات.** يخرج جميلاً بلا إعداد؛ أكثر المستخدمين لا يغيّرون شيئاً.
2. **سهولة الاستعمال للمطوّر:** واجهة برمجية صغيرة (`toast()` من أي مكان) قبل المرونة.
3. **الحالات الحدّية تُعالَج بصمت:** أوقف مؤقّت الإشعار حين يختفي التبويب، املأ الفراغ بين العناصر المكدّسة
   حتى لا ينقطع التمرير، التقط المؤشّر أثناء السحب.
4. **الانسجام:** المنحنى والمدّة والشكل والاسم بروحٍ واحدة.

## الأزرار وكل ما يُضغط
```css
.pressable { transition: transform 160ms var(--ease-out); }
.pressable:active { transform: scale(0.97); }   /* 0.95–0.98 */
```
- `:focus-visible` بحلقة واضحة (لا `outline: none` بلا بديل).
- `disabled` يشرح السبب بنصٍّ قريب أو تلميح، ولا يكون الطريق الوحيد لمعرفة الخطأ.
- حالة التحميل تحفظ عرض الزرّ (لا قفز) وتمنع الضغط المزدوج.

## النوافذ المنبثقة والقوائم
- تتكبّر من مُطلِقها (`--radix-*-transform-origin`)، والحوار من المركز.
- التلميح: تأخير أوّل (~300–500ms)، ثم فوري للمجاور (`TooltipProvider` بـ `skipDelayDuration`).
- التلميح ليس مكان معلومة ضرورية — لا يصل إليه اللمس.

## الإشعارات (sonner)
- تدخل وتخرج من الجهة نفسها، بانتقالات لا إطارات مفتاحية.
- الخطأ يبقى حتى يُغلق أو مدّة أطول؛ النجاح قصير.
- لا إشعار لما يُرى أثره مباشرة على الشاشة.

## التبويب بانتقال لون مثالي
انسخ قائمة الألسنة، لوّن النسخة كـ«نشِط»، وقصّها بـ `clip-path` على اللسان النشط وحرّك القصّ.
**النسخة زخرفية:** `aria-hidden` و`inert`، والقائمة الأصلية وحدها تحمل `role="tablist"`. وفي RTL بدّل جانبي `inset()`.

## الضغط المطوّل للحذف
طبقة `clip-path: inset(0 100% 0 0)` → `inset(0)` خلال 2s `linear` عند الضغط، وعودة 200ms `ease-out` عند الإفلات.
**فجوات يجب سدّها:** بديل لوحة مفاتيح (Enter مطوّل أو تأكيد)، ونصّ يشرح «اضغط مطوّلاً»، وفي تقليل الحركة شريط تقدّم
بلا مسح. وللحذف الخطِر (بيانات طفل، كفالة) تأكيد صريح أو تراجع لا ضغطٌ مطوّل وحده.

## الحالات الإلزامية لكل مكوّن بيانات
عادي · تحميل (هيكل بأبعاد المحتوى) · فارغ (يقول ماذا تفعل) · خطأ (يقول ماذا حدث وكيف تُعيد) · بلا صلاحية ·
«يتجهّز الآن» (ميزة لم تُفعَّل بعد).
