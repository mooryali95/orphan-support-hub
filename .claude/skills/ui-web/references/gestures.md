# الإيماءات والسحب
- **الإغلاق بالزخم:** لا تشترط تجاوز مسافة؛ السرعة تكفي.
  ```js
  const v = Math.abs(dx) / (performance.now() - startedAt); // px/ms
  if (Math.abs(dx) >= THRESHOLD || v > 0.11) dismiss();
  ```
  (`performance.now()` لا `new Date()` — رتيب ودقيق.)
- **تخميد عند الحدود:** كلما زاد السحب بعد الحدّ قلّت الحركة (`dx * 0.3` أو لوغاريتمي) — لا جدار خفيّ.
- **التقاط المؤشّر** `setPointerCapture` عند بدء السحب.
- **حماية اللمس المتعدّد:** تجاهل الإصبع الثاني بعد بدء السحب.
- **حدّث `transform` مباشرة** على العنصر أثناء السحب، لا متغيّر CSS على الأب (يعيد حساب كل الأبناء).
- **`touch-action`** صريح (`pan-y` لدرج أفقي) حتى لا يتنازع السحب مع التمرير.
- **RTL:** اتجاه السحب للإغلاق يتبع جهة الدرج المنطقية.
- **البديل إلزامي:** كل ما يُسحب يُغلق أيضاً بزرّ وبـ Escape — السحب اختصار لا الطريق الوحيد.
- المشروع يحمل `vaul` للأدراج: استعمله قبل كتابة سحبٍ يدوي.
