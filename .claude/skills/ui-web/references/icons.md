# الأيقونات
- مكتبة واحدة في السطح (المشروع: lucide-react).
- `strokeWidth={1.5}` بجانب نصّ عادي، `2` بجانب السميك. الحجم ≈ ارتفاع السطر × 0.9 (`size-4` مع `text-sm`).
- اللون `currentColor` دائماً؛ الحالة بالفئة لا بأيقونة ثانية.
- المحدَّد مملوء، الافتراضي محدَّد الخطّ.
- أيقونة بلا نصّ ← `aria-label`، وزخرفية ← `aria-hidden`.

## RTL: ماذا يُعكس
| يُعكس (`rtl:-scale-x-100`) | لا يُعكس |
|---|---|
| أسهم التنقّل، رجوع/تقدّم، شيفرون القوائم | الشعار، ✓، ✕، الساعة |
| إرسال، ردّ، خروج، قائمة منقّطة | التشغيل/الإيقاف، البحث، الرسوم البيانية |
| شريط التقدّم الاتجاهي | الأيقونات ذات النصّ اللاتيني |
