# اللغة والاتجاه

- `dir` و`lang` على الجذر، ويُعاد ضبطهما على كل كتلة بلغة أخرى (`<p dir="ltr" lang="sq">`).
- خصائص منطقية فقط: `ms/me/ps/pe/start/end/text-start/rounded-s`. ابحث: `grep -nE '\b(ml|mr|pl|pr|left|right)-' src`.
- عزل ثنائي الاتجاه: بريد، رابط، رمز (KH-0042)، رقم هاتف ← `<bdi>` أو `dir="ltr"`؛ حقول الإدخال اللاتينية `dir="ltr"` مع `text-end` في RTL.
- الأرقام: لاتينية للجداول والمبالغ والرموز والهواتف؛ هندية فقط بطلب السياق، وبقرار واحد في الصفحة (`Intl.NumberFormat('ar-u-nu-latn')`).
- التواريخ: `Intl.DateTimeFormat` بلغة الواجهة، لا تنسيق يدوي.
- الجمع العربي: `Intl.PluralRules('ar')` (zero/one/two/few/many/other) — لا «1 أعضاء».
- الترجمة الملحقة تحت النصّ الأصلي المحفوظ، لا بدلاً منه، حين يكون للنصّ قيمة قانونية (موافقات).
