# الطباعة

## العربية

- السطر: `leading-7`–`leading-8` للمتن، `leading-snug` للعناوين القصيرة فقط.
- لا `letter-spacing` ولا `tracking-*` على العربية — يقطّع الوصل. التشديد بالوزن لا بالمسافة.
- لا `text-justify` مع مدّ يدوي (ـــ). المحاذاة إلى البداية.
- خطّ عرضٍ للعناوين وخطّ متنٍ للنصّ؛ لا أكثر من عائلتين في السطح.
- الحدّ الأدنى للمتن العربي `text-base` (16px)؛ العربية تُقرأ أصغر من اللاتينية بالحجم نفسه.

## الالتفاف

```css
h1,
h2,
h3 {
  text-wrap: balance;
}
p {
  text-wrap: pretty;
}
```

تحقّق بنصٍّ عربي حقيقي: كلمةٌ طويلة قد تبقى يتيمة.

## الأرقام

- `tabular-nums` للعدّادات، المبالغ، الجداول، المؤقّتات.
- قرار الأرقام (لاتينية/هندية) واحد في الصفحة — انظر `rtl-arabic.md`.

## المبالغ

```tsx
<bdi>$1,250</bdi> // أو "⁨$1,250⁩"
```

«US$» تنقلب في سطرٍ عربي → استعمل `$`وحده، أو`USD`بعد الرقم داخل`<bdi>`.
