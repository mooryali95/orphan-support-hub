# Orphan Support Hub

بتحليل احترافي، اريد بناء نظام لليتيم بنفس الفكرة دون ان ابدا من البدايه، 
بحيث هناك يتيم، وهناك داعم وكافل لليتيم، وهناك الاداره، وهناك جهة رعاية، 
او كما ترى ، ولكن نظام متكامل لليتيم، الى ان يصل الى دعم او كفالة يتيم، من خلال المنصه بناء على البروفايل، وايضا تكامل مع منصات تحوي بروفايلات، اليتيم ،والخ 

ابن التصور كامل المقترح، وهل نبدا من البدايه ام نعدل على النظام باحترافية
