# تغيير اسم المنصّة — بلا نسيان

الاسم يعيش في مكانٍ واحد: **`src/config/brand.json`** (الاسم، الاسم اللاتيني، الشعار «نكفل… ونبني»، الوصف، لون الشريط).

## الخطوات
1. عدّل `src/config/brand.json`.
2. شغّل `bun run brand:sync`، فيقوم بثلاثة أشياء:
   - يولّد شعار البريد بالاسم الجديد (الصورة الوحيدة التي تحمل نصّ الاسم؛ العلامة نفسها بلا نصّ).
   - يكتب هجرةً تُحدّث الاسم في القاعدة (`platform_settings.brand_name`) — ومنها رسالة الترحيب.
   - يطبع ما بقي خارج الكود (اسم مشروع Lovable، `EMAIL_FROM`، منتجات Creem).
3. شغّل `bun run test` — فحص `src/config/brand.test.ts` **يفشل إن كُتب الاسم حرفياً في أي ملفٍ آخر**، فلا يبقى موضعٌ منسيّ.
4. أضف الهجرة إلى حزمة النشر: `scripts/release-bundle.sh <آخر version>`.

## ما لا يتغيّر مع الاسم (عمداً)
| | لماذا |
|---|---|
| رؤوس الـ API (`X-Api-Key`، `X-Api-Secret`، `X-Api-Timestamp`) | محايدة لا تحمل الاسم، فلا ينقطع شريك. القديمة `X-IOSO-*` ما زالت مقبولة. |
| بادئة مفاتيح الـ API (`ck_live_` / `sk_live_`) | محايدة؛ المفاتيح القديمة `ioso_…` تعمل كما هي. |
| رموز ملفّات الأيتام (`IOCO-000123`) | معرّفاتٌ ثابتة للملفّات القائمة. البادئة للجديد إعدادٌ (`platform_settings.code_prefix`) إن أُريد تغييرها. |
| أسماء ملفّات الصور (`/brand/app-192.png`، `/brand/email-logo-white.png`) | محايدة. |
