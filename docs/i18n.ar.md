# اللغات في كهاتين

العربية هي الأم، والإنجليزية لغة الرجوع، وكل دولةٍ تُربط بالمنصّة تقترح لغاتها.
اللغة الجديدة تُبنى مسودّةً كاملة، ويراجعها مكتب الدولة، وتنشرها الإدارة. الزائر
لا يرى إلا ما نُشر.

## الجماهير واللغات

| الجمهور                       | اللغات                                                                       |
| ----------------------------- | ---------------------------------------------------------------------------- |
| الزائر والكافل قبل الدخول     | العربية والإنجليزية في الكود، وأي لغةٍ مُطلقة من القاعدة (الألبانية أولاً)   |
| وليّ الأمر والمشرف في الميدان | العربية والألبانية — `src/lib/i18n.ts` (يُنقل إلى الفهرس في المرحلة التالية) |
| البوابات بعد الدخول           | العربية، وتُعرض من اليمين حتى لمن اختار لغةً أخرى                            |

## الدورة كاملة

1. **الربط يقترح:** في لوحة الإدارة ← «اللغات والترجمة»، تظهر لغات كل دولةٍ لها منصّة
   تشغيلٍ مرتبطة. المصدر هو `src/lib/country-languages.ts` (اللغات الرسمية والوطنية
   الأوسع لكل دولة). الأقليات والأقاليم تُضاف يدوياً.
2. **التفعيل:** «فعّل مسودّة» يُنشئ اللغة بحال «مسودّة»، والاسم والاتجاه من المتصفّح.
   لغةٌ تخدم أكثر من دولة (الألبانية لألبانيا وكوسوفو) تُفعَّل مرّة وتُضاف إليها الدول.
3. **المراجعون:** تسمّيهم الإدارة بالبريد، من مكتب الدولة. يراجعون لغتهم وحدها.
4. **المسودّة الآلية:** «استورد المسودّة الآلية» تُدخل الترجمة المرفقة بالكود
   (`src/i18n/drafts/<code>.json`) بأصلها «آلية»، ولا تمسّ نصّاً صحّحه إنسان.
5. **المراجعة:** في «افتح المراجعة» يرى المراجع الأصل العربي والإنجليزي والترجمة،
   ويصحّح ويحفظ مراجَعاً. «عاين الموقع بهذه اللغة» يفتح الموقع بالمسودّات له وحده،
   مع شريطٍ يقول إنها معاينة.
6. **النشر:** الإدارة تنشر المراجَع وحده. ثم «أطلق للعموم» (لا تُطلق لغةٌ بلا نصٍّ
   منشور)، فتظهر في قائمة اللغات للزائر.

كل حفظٍ ومراجعةٍ ونشر يُكتب في `ui_translation_revisions`، باسم صاحبه، ولا يُعدَّل
ولا يُحذف.

## الحمايات

| الخطر                           | ما يمنعه                                                                                                                |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| ترجمةٌ تظهر قبل أن يراجعها أحد  | العموم يقرؤون المنشور فقط، في لغةٍ مُطلقة فقط                                                                           |
| مراجعٌ ينشر بنفسه               | النشر للإدارة وحدها، وللمراجَع وحده                                                                                     |
| مسودّةٌ آلية تمحو تصحيح إنسان   | الحفظ الآلي يتجاوز ما أصله «إنسان»                                                                                      |
| تغيّر النصّ الأصلي بعد ترجمته   | لكل ترجمةٍ بصمة أصلها؛ إن تغيّر الأصل في الكود لا تُعرض الترجمة القديمة (يظهر الإنجليزي) وتُعلَّم «تغيّر أصله» للمراجعة |
| قالبٌ فقد موضع رقمه («صفحة من») | الخادم يرفض ترجمةً لا تحمل مواضع الأصل {0} {1} نفسها                                                                    |
| نصٌّ ناقص في لغة                | الرجوع إلى الإنجليزية ثم العربية — لا فراغ أبداً                                                                        |

## للمطوّر

- **النصوص:** `const COPY = defineCopy("ns", { ar: {...}, en: {...} })` ثم
  `useCopy(COPY)` في المكوّن، أو `copyOf(COPY, locale)` في `head`.
- **الجمع:** `pluralOf({ one: "{0} file", other: "{0} files" })` يعمل بفئات CLDR لكل
  لغة. والقوالب البسيطة `(n) => \`Page ${n}\`` تُترجم بمواضع مرقّمة.
- **الفهرس:** `npm run i18n:extract` بعد أي تغييرٍ في النصوص. فحص `locale.test.ts` يفشل
  إن لم يطابق الفهرس الكود، أو وُجد نصٌّ لا يُترجم (مرجعٌ لمتغيّر بدل نصّ).
- **محلياً بلا قاعدة:** `KH_DEV_DRAFT_LOCALES=sq npm run dev` يعرض المسودّة المرفقة كأنها
  منشورة. لا أثر له في البناء.
- **المتصفّح:** `E2E_EXTRA_LOCALE=sq npm run test:e2e` يضيف الألبانية إلى الفحص.

## ما يبقى بلغته عمداً

- بيانات الأطفال والبرامج والجهات: لا تُترجم آلياً.
- النصّ النبوي بلفظه العربي، ومعناه تحته.
- الشروط والخصوصية والأسئلة الشائعة: بالإنجليزية في غير العربية حتى يُترجم النصّ
  القانوني ويُعتمد. العربية هي المعتمدة.
- البريد: عربي في هذه المرحلة.

## المرحلة التالية

- مزوّد ترجمةٍ آلية يولّد المسودّة لأي لغةٍ جديدة عند تفعيلها. يحتاج إضافة حزمة
  `@anthropic-ai/sdk` (تعذّر تركيبها في بيئة هذه الجلسة) ومفتاح `ANTHROPIC_API_KEY`
  في Lovable Cloud. حتى ذلك الحين: تُولَّد المسودّة وتُرفق بالكود كما الألبانية.
- نقل قاموس الوليّ والمشرف (`src/lib/i18n.ts`) إلى الفهرس.
- حزمة الدولة: العملة وصيغة الهاتف ونماذج الموافقة بلغتها.
