# كهاتين — البوابات والإدارة

كل دورٍ بابٌ مستقل، وتجمعها صفحة **«بواباتي»** (`/workspaces`) فلا يرى المستخدم إلا ما يحقّ له.

| البوابة         | المسار                       | لمن                    | ما فيها                                             |
| --------------- | ---------------------------- | ---------------------- | --------------------------------------------------- |
| الداعم          | `/dashboard`                 | كل حساب                | كفالاته وتعهّداته                                   |
| الجهة المانحة   | `/donor/:id`                 | أعضاء جهة (شركة، وقف…) | الدعم باسم الجهة حسب النوع والهدف                   |
| المكتب          | `/office/:id`                | أعضاء المكتب           | مؤشّرات النطاق + تقارير بصور ومرفقات                |
| المؤسسة         | `/org`                       | مالك الجهة             | ملفّاتها ومستفيدوها                                 |
| المستفيد وأسرته | `/guardian`                  | الولي/الوصي            | من يرعاهم                                           |
| الإشراف         | `/supervisor`                | المشرف المعتمد         | من يشرف عليهم                                       |
| إدارة المنصّة   | `/admin` ← «المكاتب والجهات» | الإدارة                | إنشاء المكاتب، إسناد الأعضاء بالبريد، اعتماد الجهات |

## المكتب

- مسؤول عن **دولة** (المنطقة فارغة) أو **منطقة** منها، ويتبع مكتباً أعلى؛ فمدير مكتب الدولة يرى مكاتب مناطقها وينشر تقاريرها.
- الأدوار سجلّ (`office_roles`): مدير (يكتب وينشر)، منسّق وميداني (يكتبان)، مطّلع (يقرأ). تُضاف أدوار بصفّ.
- التقرير: عنوان، تفاصيل، **مؤشّرات حرّة الأسماء**، فترة، ومرفقات في خزنة خاصّة `office-media/<office_id>/…`. مسودّة ← مرفوع ← منشور.
- اللوحة تحسب نطاقه وحده: المجموعات، المستفيدون، والتعهّدات بنوعيها.

## المؤسسات

`institution_kinds` سجلّ أصناف (مركز، مكتب، مدرسة، جمعية، دار رعاية — أمثلة). دعم **التأهيل** و**العيني** كلاهما يصل المؤسسة.

## الجهة المانحة

تُسجَّل بحساب مستخدم فيصير مالكها، وتبقى «قيد المراجعة» حتى تعتمدها الإدارة؛ بعدها يُنسب التعهّد إليها ويراه أعضاؤها.
