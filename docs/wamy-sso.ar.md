# الدخول من منصّة الندوة للشباب إلى كهاتين

الهدف: من سجّل دخوله في منصّة الندوة يفتح كهاتين بضغطة، بلا تسجيلٍ ثانٍ، ويرى ما يخصّه بحسب دوره.

## القرار: إطلاقٌ موقَّع لا تضمينٌ في إطار

| الطريقة                                                    | الحكم                   | السبب                                                                                                                  |
| ---------------------------------------------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| **إطلاق موقَّع** (رابط أو زرّ في منصّة الندوة يفتح كهاتين) | **المعتمد الآن**        | يعمل مع أي نظام دخولٍ عند الندوة، ولا يحتاج تغييراً في بنيتها، والجلسة كاملة الصلاحيات والحماية                        |
| OpenID Connect (الندوة مزوّد هوية)                         | المرحلة الثانية         | المعيار الأمثل حين يكون لدى الندوة مزوّد هوية (Keycloak أو Azure AD أو Google Workspace). يحتاج إعداداً عند الطرفين    |
| تضمين كامل في iframe                                       | **غير موصى به للإدارة** | المتصفّحات تعزل تخزين الإطارات، والمصادقة الثنائية والدفع لا يعملان جيداً داخله، ويفتح باب خداع النقر على صفحات القرار |
| تضمين أدوات عرضٍ فقط (لوحة أرقام دولة)                     | لاحقاً عند الحاجة       | للعرض العامّ بلا قرارات ولا بيانات أطفال                                                                               |

## كيف يعمل الإطلاق الموقَّع

```
مستخدم مسجّل في منصّة الندوة
  → يضغط «كهاتين» (أو رابط «بيانات الدولة»)
  → خادم الندوة يوقّع رمز إطلاق لمدة دقيقة أو دقيقتين
  → POST https://<كهاتين>/api/sso/wamy   (حقل token)
  → كهاتين تتحقّق، وتعرف الحساب أو تنشئه، وتفتح الجلسة
  → المستخدم في صفحته: /country-data أو /workspaces
```

## ما يطلبه فريق الندوة التقني

يوقّع **خادم** الندوة (لا المتصفّح) رمز JWT بهذه الحقول:

| الحقل         | القيمة                                                                      |
| ------------- | --------------------------------------------------------------------------- |
| `iss`         | عنوان منصّة الندوة، مطابقٌ لـ`WAMY_SSO_ISSUER` عندنا                        |
| `aud`         | `kahatayn`                                                                  |
| `sub`         | معرّف المستخدم الثابت عند الندوة (لا البريد)                                |
| `email`       | بريده، و`email_verified: true`                                              |
| `name`        | اختياري                                                                     |
| `iat` / `exp` | الآن، والآن + 60 ثانية (الحدّ الأقصى 120)                                   |
| `jti`         | معرّف فريد لكل رمز (8 أحرف فأكثر)                                           |
| `next`        | اختياري: `/country-data` أو `/workspaces` أو `/dashboard` أو `/orphans/...` |

التوقيع: **ES256 أو RS256** بمفتاحٍ خاصٍّ عند الندوة، وتنشر مفاتيحها العامّة (JWKS) على رابطٍ نضعه في `WAMY_SSO_JWKS_URL`. هذا هو الموصى به لأنه لا سرّ مشترك. وللبدء السريع يقبل النظام **HS256** بسرٍّ مشترك (32 حرفاً فأكثر) في `WAMY_SSO_SECRET`.

## الإعداد عندنا (Lovable، أسرار الخادم)

| المتغيّر                                 | مطلوب        |
| ---------------------------------------- | ------------ |
| `WAMY_SSO_ISSUER`                        | نعم          |
| `WAMY_SSO_JWKS_URL` أو `WAMY_SSO_SECRET` | أحدهما       |
| `SUPABASE_SERVICE_ROLE_KEY`              | موجود مسبقاً |

## الحماية

1. **رمزٌ لمرّةٍ واحدة**: كل `jti` يُحجز في القاعدة، فلا يُعاد رابطٌ مسروق.
2. **عمرٌ قصير**: دقيقتان على الأكثر، مع سماحية 30 ثانية لفرق الساعة.
3. **الربط بالمعرّف**: أوّل دخولٍ يربط الحساب بالبريد الموثَّق، وبعده يُعرف بمعرّفه عند الندوة حتى لو تغيّر بريده، ولا يستولي معرّفٌ آخر على حسابٍ مربوط.
4. **الجلسة لا تمرّ بسجلّات الخادم**: رمز الدخول يُسلَّم في جزء الرابط (#) ويُمسح من الشريط فوراً.
5. **الدخول لا يمنح دوراً**: الدور من فريق الدولة أو الإدارة كما هو. فليكن بريد العضو في فريق الدولة هو بريده في منصّة الندوة.
6. **المصادقة الثنائية باقية**: المدير أو المشرف الذي فعّلها يُطلب منه رمزها بعد الدخول.
7. **الوجهة من قائمةٍ مسموحة**: لا يُعاد التوجيه إلى موقعٍ خارجي.

## مثال توقيع (Node.js عند الندوة)

```js
import { SignJWT, importPKCS8 } from "jose";
const key = await importPKCS8(process.env.KAHATAYN_PRIVATE_KEY, "ES256");
const token = await new SignJWT({
  email: user.email,
  email_verified: true,
  name: user.name,
  next: "/country-data",
})
  .setProtectedHeader({ alg: "ES256", kid: "wamy-2026" })
  .setIssuer("https://youth.wamy.org")
  .setAudience("kahatayn")
  .setSubject(String(user.id))
  .setIssuedAt()
  .setExpirationTime("60s")
  .setJti(crypto.randomUUID())
  .sign(key);
// ثم نموذج POST تلقائي إلى https://<كهاتين>/api/sso/wamy بحقل token
```
