# التصوّر الفني للتكامل وآلية إضافة الأيتام

إلى: الفريق التقني والإدارة في الندوة العالمية للشباب الإسلامي
المرجع: محضر اجتماع 24 نوفمبر 2026، البند الأوّل
الحالة: وثيقة عمل للنقاش

## دليل القراءة

| العلامة         | المعنى                                                |
| --------------- | ----------------------------------------------------- |
| **مبني**        | موجود في الشيفرة وله اختبار أو هجرة يمكن الرجوع إليها |
| **مقترح**       | تصوّر لم يُنفَّذ بعد، يُعرض للقرار                    |
| **يلزم الندوة** | لا يكتمل إلا بمعلومة أو قرار أو موارد من الندوة       |

لا يوجد اليوم تكامل حيّ بين منصّة الندوة وكهاتين. ما يرد هنا قدرات جاهزة في المنصّة تنتظر تفعيلها مع الندوة، ولا تدّعي الوثيقة أيّ اعتماد أو تدقيق خارجي.

## 1. الغرض

أن تصل بيانات الأيتام من الندوة إلى كهاتين بمسار واحد موثوق، فلا يُنشأ ملف طفل إلا من سجلّ الندوة، ولا تتغيّر قيمة حرجة بلا اعتماد بشري، وأن يدخل موظفو الندوة بحسابهم القائم دون تسجيل ثانٍ.

## 2. البنية العامة (مبني)

تبني المنصّة لكل طفل «سجلّاً ذهبياً»: قيمة معتمدة لكل حقل، يُحفظ معها مصدرها ووقتها. الندوة هي المصدر الرئيس، ومنصّة التشغيل في مكتب الدولة مؤكِّد يكشف الفروق. السلطة تُحدَّد لكل حقل في جدول `field_authority`، ويطابقه `FIELD_RULES` في `src/lib/golden-record.ts` باختبار يقفل التطابق.

| مجموعة الحقول                                                | المالك  | المؤكِّد | درجة الخطر                  |
| ------------------------------------------------------------ | ------- | -------- | --------------------------- |
| الهوية: الاسم، الميلاد، الجنس، الدولة                        | الندوة  | المكتب   | الميلاد والجنس والدولة حرجة |
| الأهلية وحالة البرنامج                                       | الندوة  | المكتب   | حرج                         |
| الوضع الحالي: المنطقة، المدينة، الدراسة، الوصي، السكن، الصحة | المكتب  | الندوة   | منخفض أو متوسط              |
| تقارير التقدّم                                               | المكتب  | لا أحد   | منخفض                       |
| مسارات التأهيل                                               | المكتب  | المنصّة  | منخفض                       |
| الكفالات والمال                                              | المنصّة | الندوة   | لا يُستورد أبداً            |

قواعد ثابتة في النواة `golden_ingest_core`: الخلية الفارغة لا تمسح قيمة، والملاحظة الأقدم لا تغلب الأحدث، والحقل الحرج لا يتغيّر إلا باعتماد، والقيمة المرفوضة لا تعيد فتح البند، وملف الطفل المكفول يمرّ بقفل الهوية فلا يُعدَّل إلا بطلب فكّ بموافقتين. وحقول الهوية لملف مربوط بالندوة لا تُكتب مباشرة على الجدول ولو من مدير (هجرة `security_hardening`).

## 3. قناتا الإدخال

كلتا القناتين تمرّان بالنواة نفسها، فلا فرق في القواعد بينهما.

### 3.1 استيراد CSV (مبني، متاح اليوم)

ترفع الإدارة أو فريق الدولة ملف CSV بقالب لكل مصدر من شاشة «مصادر التحقق». وهو المسار المقترح للبدء مع الندوة قبل أيّ ربط آلي.

### 3.2 الواجهة البرمجية `POST /api/integrations/records` (مبنية، غير مفعّلة مع الندوة)

**المصادقة:** ترويسات `X-Api-Key` و`X-Api-Secret` و`X-Api-Timestamp`. السرّ يُحفظ عندنا مجزّأً بـscrypt مع ملح فلا يُسترجع، والمقارنة ثابتة الزمن، والختم الزمني يُرفض خارج نافذة خمس دقائق.

| النطاق            | يكتب باسم         | الشرط                                            |
| ----------------- | ----------------- | ------------------------------------------------ |
| `records:primary` | الندوة            | لا يرتبط بمنصّة مكتب                             |
| `records:verify`  | منصّة مكتب الدولة | لا يُقبل إلا والدولة في وضع `shadow` أو `active` |

الحقل الذي لا يملكه المصدر ولا يؤكّده يُتخطّى ويُسمّى في الردّ.

**مثال الحمولة:**

```json
{
  "country": "LK",
  "records": [
    {
      "external_ref": "W-1",
      "observed_at": "2026-11-01T00:00:00Z",
      "fields": {
        "display_name": "…",
        "birth_date": "2015-03-01",
        "education_stage": "…"
      }
    }
  ]
}
```

**منع التكرار والإعادة:** كل طلب كتابة يحمل أحادية تُقبل مرّة واحدة، إمّا `X-Api-Nonce` من المرسل أو بصمة الطلب نفسه (الختم والطريقة والمسار وبصمة الجسم). هذا المسار يتجاهل ترويسة `Idempotency-Key` عمداً ويعتمد البصمة، فالطلب الملتقَط لا يمرّ مرّتين، والمرسل الذي يعيد المحاولة يولّد ختماً جديداً. وإعادة الملاحظة نفسها لا تقلب القيمة المعتمدة لأن الأقدم لا يغلب الأحدث.

| الحدّ                         | القيمة               |
| ----------------------------- | -------------------- |
| حجم الجسم                     | 2 ميغابايت           |
| السجلّات في الدفعة            | من 1 إلى 2000        |
| المعدّل قبل المصادقة لكل مصدر | 120 طلباً في الدقيقة |
| المعدّل لكل مفتاح             | 300 طلب في الدقيقة   |
| نافذة الختم الزمني            | 5 دقائق              |

| الرمز                                                            | الحالة | المعنى                              |
| ---------------------------------------------------------------- | ------ | ----------------------------------- |
| `missing_credentials`، `stale_timestamp`، `invalid_credentials`  | 401    | مصادقة ناقصة أو قديمة أو غير صالحة  |
| `scope_denied`                                                   | 403    | المفتاح بلا أحد النطاقين            |
| `invalid_json`، `country_required`، `invalid_nonce`              | 400    | حمولة غير صالحة                     |
| `body_too_large`، `batch_invalid`                                | 413    | تجاوز الحجم، أو دفعة فارغة أو كبيرة |
| رمز من القاعدة مثل `country_source_mode` و`client_not_permitted` | 422    | رفضت النواة الدفعة                  |
| `apply_failed`                                                   | 500    | تعذّر التطبيق                       |
| تجاوز المعدّل                                                    | 429    | يُعاد الطلب بعد انقضاء النافذة      |

## 4. ربط الهوية وطابور الربط (مبني)

1. الربط بالمعرّف وحده: الزوج `(source, external_ref)` يدلّ على يتيم واحد.
2. السجلّ الذي لا رابط له يقف في `source_link_queue` مع مرشّحين بالاسم المطبَّع والميلاد والجنس.
3. لا يُنشأ ملف تلقائياً. المشرف يربط، أو ينشئ ملفاً من سجلّ الندوة وحده، أو يتجاهل. وللاستيراد الأوّل إنشاء جماعي لسجلّات الندوة التي لا مرشّح لها.
4. المطابقة تجري على النص المطبَّع `golden_canon`، فاختلاف الإملاء لا يصير تعارضاً ولا تُدمج الأسماء تلقائياً.

## 5. الدخول الموحّد برمز إطلاق موقَّع (مبني، ينتظر مفاتيح الندوة)

يوقّع **خادم** الندوة رمز JWT قصير العمر ويرسله بنموذج POST إلى `/api/sso/wamy` في حقل `token`.

| الحقل        | القيمة                                                                                      |
| ------------ | ------------------------------------------------------------------------------------------- |
| `iss`        | عنوان منصّة الندوة، مطابق لـ`WAMY_SSO_ISSUER`                                               |
| `aud`        | `kahatayn`                                                                                  |
| `sub`        | معرّف المستخدم الثابت عند الندوة                                                            |
| `email`      | البريد مع `email_verified: true`                                                            |
| `name`       | اختياري                                                                                     |
| `iat` و`exp` | عمر لا يتجاوز 120 ثانية، مع سماحية 30 ثانية لفرق الساعة                                     |
| `jti`        | معرّف فريد لكل رمز                                                                          |
| `next`       | اختياري من قائمة مسموحة: `/country-data`، `/workspaces`، `/dashboard`، `/admin`، `/orphans` |

**التوقيع:** ES256 أو RS256 بمفاتيح عامة منشورة (JWKS) في `WAMY_SSO_JWKS_URL`، وهو الموصى به. وللبدء يُقبل HS256 بسرّ مشترك في `WAMY_SSO_SECRET`. وأيّ خوارزمية أخرى تُرفض.

**الحماية المبنية:**

1. كل `jti` يُحجز في القاعدة فيُستعمل مرّة واحدة.
2. ترويسة `Origin` تُطابَق مع قائمة مسموحة مبنية على عنوان المُصدِر.
3. الجلسة لا تُسلَّم في الرابط: تُحفظ في الخادم وتُسلَّم مرّة واحدة بأحادية في جزء الرابط تُطابَق مع كعكة `HttpOnly` عمرها دقيقتان، فالرابط المرسَل لشخص آخر لا يفتح شيئاً.
4. الحساب يُعرف بـ`sub` في `sso_identities`، ولا يُربط ببريد غير موثَّق.
5. **الرمز لا يمنح دوراً.** الدور يأتي من فريق الدولة أو الإدارة وحدهما.
6. المصادقة الثنائية تبقى مطلوبة بعد الدخول لمن يحسم.
7. معدّل مستقلّ للدخول الموحّد: 20 محاولة في الدقيقة.

## 6. الأمن (مبني)

| الآلية                     | التفصيل                                                                                              |
| -------------------------- | ---------------------------------------------------------------------------------------------------- |
| مفاتيح الشركاء             | سرّ مجزّأ لا يُسترجع، وإبطال فوري من الإدارة يُكتب في `integrity_log`                                |
| حدود المعدّل               | دلاء مستقلّة للتكامل ولكل مفتاح وللدخول الموحّد                                                      |
| المصادقة الثنائية للحاسمين | المدير ومشرف الدولة يحتاجان جلسة aal2 للحسم، وإلّا يعود `mfa_required`                               |
| العينان                    | التغيير الحرج والتنبيه الحرج لا يحسمهما من رفعهما، والمدير غير مستثنى                                |
| سجلّ التدقيق والسلامة      | `audit_log` للقرارات، و`integrity_log` للرفض وإخفاق الدخول، و`orphan_field_history` غير قابل للتعديل |
| إيقاف الدخول الموحّد       | `platform_settings.sso_disabled`                                                                     |
| تجميد ملف طفل              | `orphan_freezes`: لا كتابة ذهبية ولا كفالة جديدة ولا رفع تحديثات                                     |
| إيقاف الدفع والبريد        | `payments_on_hold` و`email_on_hold` وفق دليل التشغيل                                                 |

## 7. انضمام كل دولة

ينتقل وضع منصّة المكتب في كل دولة عبر `admin_country_source_set`، ولا يغيّره إلا المدير. كل انتقال يعيد تقييم الملاحظات المحفوظة، فلا يُعاد إرسال شيء والرجوع ممكن.

| الخطوة | الوضع    | ما يحدث                                                                |
| ------ | -------- | ---------------------------------------------------------------------- |
| 1      | `none`   | الندوة تملك كل الحقول، والاستيراد بـCSV أو بمفتاح `records:primary`    |
| 2      | `shadow` | منصّة المكتب ترسل بمفتاح `records:verify` وتُكشف الفروق دون تغيير قيمة |
| 3      | `active` | المكتب يتسلّم حقول الوضع الحالي، والندوة تؤكّدها                       |

قبل كل خطوة يُعيَّن فريق الدولة: مشرفان على الأقل، ومدخلو بيانات، ومطّلعون، لأن قاعدة العينين تحتاج شخصين.

## 8. ما نحتاجه من الندوة (يلزم الندوة)

| البند                                         | الغرض                                  |
| --------------------------------------------- | -------------------------------------- |
| عنوان المُصدِر `iss`                          | التحقق من رمز الدخول                   |
| رابط JWKS أو سرّ مشترك مؤقّت                  | توقيع الدخول                           |
| قائمة الحقول المتاحة عند الندوة وتعريفاتها    | مطابقة `field_authority`               |
| شكل المعرّف `external_ref` وثباته             | الربط بالمعرّف                         |
| بيئة اختبار ببيانات غير حقيقية                | التجربة قبل أيّ بيانات أطفال           |
| مسؤول تقني ومسؤول بيانات لكل دولة تجريبية     | التواصل والحسم                         |
| مصدر رسمي لبيانات الحضور في سريلانكا وباكستان | تحديث `source` و`url` في بيانات الشبكة |

## 9. خطة تجريبية لدولة واحدة (مقترح)

| المرحلة | المدّة المقترحة | العمل                                                    | معيار الخروج                        |
| ------- | --------------- | -------------------------------------------------------- | ----------------------------------- |
| أ       | أسبوعان         | مفاتيح اختبار، وإعداد الدخول الموحّد، وتعيين فريق الدولة | دخول ناجح لعضو فريق وحسم بجلسة aal2 |
| ب       | ثلاثة أسابيع    | استيراد CSV من الندوة في وضع `none`، وتفريغ طابور الربط  | لا سجلّ معلّق بلا قرار              |
| ج       | أربعة أسابيع    | منصّة المكتب في `shadow` بمفتاح `records:verify`         | فروق مفهومة وموثّقة                 |
| د       | قرار مشترك      | الانتقال إلى `active` أو البقاء أو الرجوع                | قرار مكتوب من الطرفين               |

تُختار الدولة من دول التركيز الحالية (سريلانكا، باكستان، تايلند، السودان، السنغال) بقرار من الندوة.
