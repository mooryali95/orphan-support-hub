# تصوّر آليات الموثوقية والشفافية

إلى: الإدارة والفريق التقني في الندوة العالمية للشباب الإسلامي
المرجع: محضر اجتماع 24 نوفمبر 2026، البند الثاني
الحالة: وثيقة عمل للنقاش

العلامات: **مبني** موجود في الشيفرة، و**مقترح** لم يُنفَّذ، و**يلزم الندوة** ينتظر قرارها. لا تدّعي الوثيقة اعتماداً أو تدقيقاً خارجياً أو تكاملاً حيّاً.

## 1. المبادئ

1. لكل حقل مالك واحد، ولا يغلب مصدرٌ الآخر بصمت.
2. لا تغيير حرج بلا شخصين: من يرفع لا يحسم.
3. الكشف آليّ والقرار بشري.
4. الكافل يرى مستوى الثقة لا تفاصيلها، حفاظاً على خصوصية الطفل.
5. كل قرار يترك أثراً غير قابل للتعديل.
6. لا يُعرض رقم تجريبي على أنه نتيجة.

## 2. السجلّ الذهبي والسلطة لكل حقل (مبني)

الندوة المصدر الرئيس، ومنصّة المكتب مؤكِّد. السلطة لكل حقل في `field_authority`، والحقول الحرجة (الميلاد والجنس والدولة والأهلية وحالة البرنامج) لا تتغيّر إلا باعتماد. التفصيل في `docs/wamy/integration-concept.ar.md` و`docs/golden-record.ar.md`.

## 3. إشارات كشف التلاعب (مبني)

كل ملاحظة تمرّ بزناد `golden_detect`، والمقارنة على النص المطبَّع `golden_canon`.

| الإشارة                    | الدرجة | ما تكشفه                                                 |
| -------------------------- | ------ | -------------------------------------------------------- |
| `hidden_characters`        | تحذير  | محارف خفية أو عاكسة للاتجاه في الاسم                     |
| `mixed_script`             | تحذير  | كلمة تخلط أبجديتين                                       |
| `cosmetic_change`          | معلومة | فرق تشكيل أو همزة يطويه التطبيع                          |
| `subtle_edit`              | تحذير  | تغيّر حرف أو حرفين في اسم أو وصي                         |
| `age_shift`                | حرج    | تحرّك الميلاد ستة أشهر فأكثر أو عبر سنّ 18               |
| `flip_flop`                | تحذير  | عودة قيمة لما كانت عليه خلال 60 يوماً                    |
| `change_after_sponsorship` | حرج    | تغيّر حقل حرج لطفل مكفول                                 |
| `possible_duplicate`       | حرج    | ملف آخر بالاسم والميلاد والجنس نفسها في الدولة           |
| `bulk_change`              | تحذير  | مصدر غيّر حقلاً في 25 ملفاً فأكثر وخُمس الدولة خلال ساعة |

التنبيه الحرج يجعل الملف «موسوماً»، ويحسمه المشرف بإحدى ثلاث: «روجِع»، أو «إنذار كاذب»، أو «تلاعب مؤكَّد» بسبب مكتوب.

## 4. العينان والمصادقة الثنائية (مبني)

| الضابط            | التطبيق                                                                            |
| ----------------- | ---------------------------------------------------------------------------------- |
| العينان           | التغيير الحرج والتنبيه الحرج وتحديثات الطفل لا يحسمها من رفعها، والمدير غير مستثنى |
| المصادقة الثنائية | الحسم يحتاج جلسة aal2 للمدير ومشرف الدولة                                          |
| حدود الدولة       | كل باب يفحص `country_can` قبل حالة البند، فلا يعرف فريق دولة شيئاً عن غيرها        |
| السجلّ            | الرفض بسبب العينين أو غياب aal2 يُكتب في `integrity_log`                           |

لذلك يلزم لكل دولة مشرفان على الأقل، وللإدارة مديران على الأقل. **يلزم الندوة** تسميتهم.

## 5. شرط الثقة على الكفالة الجديدة (مبني)

`golden_accepts_new_support` يرفض الكفالة الجديدة لملف موسوم أو متعارض أو بمصدر واحد حيث يوجد مؤكِّد، أو مجمَّد. ويُقرأ الشرط في ثلاثة مواضع: زناد قبل الإدراج على `sponsorships` يرفض بـ`file_under_verification` للجميع ومنهم الإدارة، ودالّتا الاقتراح لا تقترحان ملفاً سيُرفض، وصفحة الطفل تقفل زرّ الكفالة. الكفالات القائمة لا تُمسّ، والإيقاف قرار بشري. والشرط فحص مفهرس يطابق `golden_trust` باختبار، فيبقى سريعاً عند عشرة آلاف ملف.

## 6. شارة التحقق للكافل والخصوصية (مبني)

`public_verification` تعيد لملف منشور درجة من ثلاث وشهر آخر تحقّق، ولا شيء غيرهما.

| الدرجة          | المعنى                           |
| --------------- | -------------------------------- |
| موثّق من مصدرين | الندوة والمكتب متطابقان          |
| موثّق من الندوة | الندوة وحدها حيث لا مؤكِّد فعّال |
| قيد التحقق      | بند مفتوح أو تنبيه أو مصدر واحد  |

أسباب التنبيه وقيم الحقول تبقى للإدارة وحدها، والصور والمواقع الخاصة تبقى خلف بوّابة الوصول إلى الطفل.

## 7. تحديثات الطفل بموافقة الوليّ ومراجعة (مبني)

1. يرفع فريق الدولة صوراً حتى 5MB أو مقاطع قصيرة حتى 40MB أو ملاحظات، وموافقة الوليّ شرط لكل وسيط.
2. الحسم بيد من يملك الاعتماد في دولة الطفل، بجلسة aal2، ومن غير الرافع، والرفض بسبب يُكتب في السجلّ.
3. الكافل يرى المعتمد وحده لطفل يكفله كفالة نشطة، بروابط موقَّعة قصيرة العمر.
4. لا رفع لطفل مجمَّد.

## 8. الشفافية المالية

| الآلية                             | الحالة | التفصيل                                                                                     |
| ---------------------------------- | ------ | ------------------------------------------------------------------------------------------- |
| سجلّ الكفالة                       | مبني   | لكل شهر مستحق: هل دُفع، وهل حُوِّل للجهة، وهل وصل الطفل، والوصول يُثبَت بمستند              |
| إيصال الشهر                        | مبني   | بصمة قصيرة لحقائق الشهر تتغيّر إن تغيّرت حقيقة لاحقاً، فيظهر الفرق عند التحقق               |
| السجلّ السنوي للتبرّعات            | مبني   | صفحة سنوية للكافل تجمع تبرّعاته                                                             |
| الزكاة                             | مبني   | السجلّ لا يصنّف التبرّعات زكاةً ولا يذكر خصماً ضريبياً، والأهلية تتبع سياسة الندوة المنشورة |
| المطابقة المالية الشهرية مع الندوة | مقترح  | لم تُنفَّذ، و**يلزم الندوة** تحديد صيغتها                                                   |

## 9. استبقاء البيانات (مبني)

| البيانات                           | المدّة                                                   |
| ---------------------------------- | -------------------------------------------------------- |
| وسيط تحديث مرفوض                   | يُحذف فور الرفض، ويُمحى الصفّ بعد 30 يوماً               |
| تحديثات طفل مؤرشَف بلا كفالة قائمة | تُمحى بعد 365 يوماً افتراضاً، قابلة للضبط ولا تقلّ عن 30 |
| سجلّ الحقول `orphan_field_history` | غير قابل للتعديل                                         |

الحذف على مرحلتين: يُحذف الملف أوّلاً ثم الصفّ. **يلزم الندوة** إقرار المدد أو تعديلها.

## 10. السجلّات (مبني)

`audit_log` لكل قرار حسم، و`integrity_log` للإدارة وحدها يحفظ رفض العينين ورفض `mfa_required` وإبطال المفاتيح وإخفاق الدخول الموحّد بسببه دون الرمز أو البريد. ويحدّد دليل التشغيل حفظ هذه السجلّات أدلّةً قبل أيّ إصلاح عند حادث، والإبلاغ خلال 72 ساعة.

## 11. مشاركة مكاتب الندوة (مبني)

| الدور       | يرى      | يرفع | يحسم ويربط | يدير الفريق                      |
| ----------- | -------- | ---- | ---------- | -------------------------------- |
| الإدارة     | كل الدول | نعم  | نعم        | يعيّن المشرفين ويغيّر وضع المصدر |
| مشرف الدولة | دولته    | نعم  | نعم        | يضيف مدخلي البيانات والمطّلعين   |
| مدخل بيانات | دولته    | نعم  | لا         | لا                               |
| مطّلع       | دولته    | لا   | لا         | لا                               |

البوّابة `/country-data`، والدخول إليها من منصّة الندوة بالدخول الموحّد عند تفعيله.

## 12. مؤشرات قياس التجربة (مقترح)

| المؤشر                                   | الهدف المقترح للنقاش               |
| ---------------------------------------- | ---------------------------------- |
| نسبة الملفات «موثّق من مصدرين» في الدولة | ترتفع شهرياً                       |
| زمن حسم التنبيه الحرج                    | أقلّ من 5 أيام عمل                 |
| السجلّات المعلّقة في طابور الربط         | صفر في نهاية كل مرحلة              |
| نسبة الإنذارات الكاذبة                   | تُقاس وتُراجع القواعد عليها        |
| تحديثات الطفل المعتمدة لكل كفالة نشطة    | تحديث واحد كل ثلاثة أشهر على الأقل |
| الأشهر المثبَت وصولها بمستند             | ترتفع شهرياً                       |

## 13. قرارات مفتوحة

1. الدولة التجريبية الأولى.
2. توقيع الدخول: JWKS من البداية أم سرّ مشترك مؤقّت.
3. إقرار مدد الاستبقاء.
4. صيغة المطابقة المالية الشهرية.
5. معالجة أحداث الخروج من البرنامج (`exited`): الاعتماد ثم الأرشفة بالمسار القائم.
6. تمرير مرآة الرواد الحالية `/api/integrations/mirror` بطبقة السجلّ الذهبي، فهي اليوم تكتب الملف مباشرة.
7. المصدر الرسمي لحضور الندوة في سريلانكا وباكستان.
