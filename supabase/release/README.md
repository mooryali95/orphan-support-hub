## الخطوات

1. **افحص ما طُبّق:** شغّل `00-check-applied.sql` في Lovable Cloud ← SQL (قراءة فقط)، وانسخ أحدث `version`.
2. **إن ظهرت الهجرات الجديدة كلّها مطبّقة** (قد يطبّقها Lovable تلقائياً عند الاستئناف): توقّف، لا شيء تفعله.
3. **وإلا:** إن كان أحدث رقم `20260904100000` فشغّل `bundle-after-20260904100000.sql` كما هو. وإن كان رقماً آخر فولّد الملف المناسب:
   ```
   scripts/release-bundle.sh <أحدث version>
   ```
4. **افحص الأمان:** شغّل `03-smoke-test.sql` (قراءة فقط). كل سطرٍ يجب أن يكون `true`؛ أيّ `false` يوقف النشر.
5. **عبّئ ألبانيا:** شغّل `02-seed-albania.sql` (تكراره آمن) — مكتب ألبانيا الوطني.
6. **انشر الواجهة** من Lovable ← Publish، بعد نجاح الخطوات السابقة لا قبلها.
7. **من الواجهة:** أسند أعضاء مكتب ألبانيا، واربط الرواد بجهتها (الإدارة ← المنصّة ← التكامل)، وأصدر مفتاح «مزامنة منصّة التشغيل» للرواد.

## الأمان

- الملف **معاملة واحدة**: إن فشل سطرٌ واحد رُجع كل شيء، فلا تبقى القاعدة نصف مطبّقة.
- كل هجرة تفحص أولاً أنها لم تُطبَّق؛ فإن كانت مطبّقة توقّف الملف كاملاً برسالة «مطبّقة سلفاً». التخمين الخاطئ لا يضرّ.
- جُرِّب على قاعدة نظيفة: طُبّق الملف، سُجّلت هجراته، ورُفض تشغيله مرة ثانية.
